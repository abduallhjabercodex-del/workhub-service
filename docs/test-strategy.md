# Day 4 — Test Strategy and Quality Evidence

## الهدف

تركز استراتيجية الاختبار على المخاطر الأعلى في WorkHub: قواعد صحة المدخلات، أخطاء الموارد غير الموجودة، تحويل HTTP إلى حالات الاستخدام، سلامة middleware، والتزام المستودع داخل الذاكرة بالعقود المحددة.

## هرم الاختبارات

| المستوى            | الاختبارات الحالية                         | المخاطر المغطاة                                                              |
| :----------------- | :----------------------------------------- | :--------------------------------------------------------------------------- |
| Unit               | اختبارات `config` و`service` و`middleware` | التحقق، حالات المجال، الحالات الفاشلة، request ID، timeout، وpanic recovery. |
| Integration / HTTP | `internal/handler/api_test.go`             | تدفق إنشاء مشروع ومهمة وتحديث مهمة وغلاف أخطاء التحقق.                       |
| Benchmark          | `internal/repository/memory_test.go`       | قياس استعراض 1000 مهمة مع التصفية والترتيب.                                  |
| End-to-end         | تشغيل الخدمة وطلبات curl                   | إثبات أن wiring الكامل يعمل من HTTP إلى repository.                          |

## الفحوص الآلية

تم تشغيل `gofmt` و`go test ./...` و`go vet ./...` و`go test -race ./...` و`go test -cover ./...`. كما تم تشغيل benchmark خاص بالمستودع.

التغطية الإجمالية الحالية في تقرير `docs/coverage.txt` هي **42.6%**. هذه النسبة تفسيرية وليست هدفًا وحيدًا للجودة؛ فاختبارات حالات الفشل وحدود النظام أهم من رفع الرقم دون تغطية مخاطر حقيقية.

## النتائج

جميع الاختبارات والفحوص الحالية ناجحة. قياس benchmark المرجعي على بيئة التنفيذ كان تقريبًا `106229 ns/op` مع `303131 B/op` و`15 allocs/op` لكل عملية استعراض للقائمة المكونة من 1000 مهمة.

## الفجوات المعروفة

ما زال المستودع داخل الذاكرة ولا توجد اختبارات قاعدة بيانات أو اختبارات تحميل متعددة المستخدمين. كما أن المصادقة والصلاحيات غير مفعلة بعد، ولا يتم التحقق من ملف OpenAPI آليًا داخل CI. هذه فجوات مقصودة في نطاق الأيام الأولى ويجب معالجتها قبل بيئة إنتاج حقيقية.

## كيفية إعادة التشغيل

```bash
gofmt -w cmd/server internal
go test ./...
go vet ./...
go test -race ./...
go test -coverprofile=docs/coverage.out ./...
go test -run '^$' -bench BenchmarkListTasks -benchmem ./internal/repository
```
